Featured DevOps · Command-line tool

vpnctl: several VPNs, side by side

VPN clients like FortiClient connect you to one network at a time, so working across several meant constantly disconnecting, logging back in and approving MFA prompts. vpnctl runs each VPN in its own Docker container and exposes it on the Mac as a local SOCKS5 + HTTP proxy. Every session stays connected, and you choose which one each app goes through.

  • Route the whole Mac, a single terminal, a Chrome window, an SSH session or one command through any VPN
  • Companion Chrome extension (Manifest V3) switches your everyday browser between sessions in one click
  • Per-database port forwards, so tools like DBeaver can reach databases behind different VPNs at once
  • Self-healing: auto-reconnects with Duo MFA, sends keep-alives, and holds off sleep while a tunnel is up
  • Passwords live in the macOS Keychain and go straight into the container, never written to disk

Restaurant website: order from the table

A QR-code ordering system for a restaurant. Customers scan the code on their table, browse the menu and order from their phone without creating an account, then pay online with Razorpay or at the desk. Staff work every order from a private dashboard that updates the moment something changes.

  • Every order is tied to the table it came from, and customers follow its progress on a live status screen
  • The server enforces the order workflow: steps can't be skipped or reversed, and a rejected order shows the customer why
  • Secure online payments: prices are always calculated on the server, and each payment's signature is checked before an order is marked paid
  • Admins manage the menu (with photo uploads), tables, QR codes and staff accounts behind JWT login, hashed passwords and rate limiting

Machine learning · Healthcare

Stroke risk prediction

A model that predicts whether a patient is likely to have a stroke from routine details: age, gender, BMI, average glucose level, hypertension, heart disease, work type and smoking habits. It's trained with a Random Forest on 5,110 real patient records.

  • Explored the data with pandas and seaborn: class balance, category counts and IQR outliers in BMI and glucose
  • Filled the 201 missing BMI values with the median instead of dropping them, since 40 of those patients had a stroke
  • One-hot encoded categories like work type and smoking status, and standardised age, BMI and glucose
  • Only 4.9% of patients had a stroke, so the minority class was oversampled to stop the model always guessing "no stroke"
  • Trained a 100-tree Random Forest on an 80/20 split and tested it on hand-entered patient details

Hackathon Machine learning · Tax data

GST machine-learning model

A binary classifier built by team GSTN_716 for the GSTN hackathon, trained on anonymised GST (Goods and Services Tax) records with separate training and test sets. Most of the work went into making messy, incomplete, imbalanced data usable, then checking that an XGBoost model held up on it.

  • Filled gaps column by column: the mean for simple columns, and scikit-learn's IterativeImputer to estimate the rest
  • Used XGBoost's feature importances to find and drop columns that weren't helping the model
  • Balanced the two classes with SMOTE, so the model couldn't score well by favouring the larger one
  • Checked stability with 5-fold stratified cross-validation, charting F1 and ROC AUC for each fold
  • Varied the number of trees from 1 to 30 and compared training and test scores to catch overfitting
